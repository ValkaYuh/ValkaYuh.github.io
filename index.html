  Case file

The test cases nobody could run

Adding a new card triggered an authentication step that fired off a chain of requests. That chain could not be reproduced by hand through the API, so a whole group of test cases around new card authentication was blocked. My fix was to split the job between the tools that could each handle part of it:

  1. Java + TestNGDrive the flow through the API up to the authentication step.
  2. Hand offTake the request that triggers the chain.
  3. Headless browserOpen it with Selenium and let the chain complete on its own.
  4. UnblockedNew card authentication works in tests, and the blocked cases run.
